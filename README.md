# Shopee Chat Translator Chrome Extension

Shopeeのチャット画面で利用できる翻訳ツールです。日本語で話した内容を自動的に相手の言語へ翻訳して入力し、受信した外国語のメッセージを日本語へ置き換えます。

## 主な機能

- 🎤 **音声入力翻訳**: チャット入力欄に追加されるマイクボタンから日本語で話すと、設定した相手の言語に翻訳されたテキストを自動挿入します。
- 🌐 **受信メッセージの自動翻訳**: 外国語のチャットメッセージを検出すると、日本語の翻訳と元言語情報をメッセージ下部に表示します。
- ⚙️ **柔軟な設定**: オプションページで音声認識言語、送信メッセージの翻訳先、受信メッセージの翻訳先、そして自動翻訳のオン/オフを切り替えられます。

## インストール手順

1. このリポジトリをダウンロードまたはクローンします。
2. Chromeで `chrome://extensions/` を開き、右上の「デベロッパーモード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」から本フォルダを選択します。
4. Shopeeのチャットページを開き、入力欄に追加されたマイクボタンと自動翻訳を確認してください。

## 設定

1. 拡張機能のカードにある「詳細」ボタンから「拡張機能のオプション」を開きます。
2. 以下を設定できます。
   - 音声認識に使用する言語（初期値: 日本語）
   - 相手の言語（送信メッセージの翻訳先、初期値: 英語）
   - 受信メッセージの翻訳先（初期値: 日本語）
   - 受信メッセージの自動翻訳を有効にするかどうか

設定内容はChrome Syncストレージに保存され、ログインしているChrome間で同期されます。

## 技術的なポイント

- 翻訳には `https://translate.googleapis.com/` の公開エンドポイントを利用します。
- 音声入力にはブラウザの Web Speech API (`webkitSpeechRecognition`) を使用します。対応ブラウザでのみ動作します。
- MutationObserver を使って新しいメッセージを監視し、翻訳結果を自動で挿入します。

## 免責事項

- Googleの翻訳エンドポイントは予告なく仕様変更される可能性があります。
- ShopeeのDOM構造が変更された場合、メッセージ検出が正しく機能しない場合があります。
- 音声認識はブラウザ・OSの対応状況に依存します。
